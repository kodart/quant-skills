# Quant — Claude Code plugin marketplace

Generated by `scripts/build-plugin.sh` from a private source repository. **Do
not edit in place** — changes here are overwritten by the next build; edit
`plugin/` or `skills/` at the source instead.

## Install

```
/plugin marketplace add kodart/quant-skills
/plugin install quant@quant
```

That is one step for two things: the `quant` MCP server and the reviewed skills
that know how to drive it. Then point it at your endpoint:

```
export QUANT_MCP_URL=https://…/mcp
```

Full documentation is in [plugins/quant/README.md](plugins/quant/README.md).

Plugin version `0.1.0`.
